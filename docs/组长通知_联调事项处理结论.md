- **问题**：无 LLM key 时规则模式姓名为空（仅提取邮箱/电话）。
- **修复**：`services/resume_parser.py` 新增 `_rule_name` 启发式——优先「姓名：」显式字段，其次单独一行的 2~4 字纯中文（黑名单过滤「个人简历/求职意向」等标题），并在 LLM 未识别姓名时回填规则结果。新增 5 个单元测试。
