## 1. 项目概述

**AI 智能面试官与人才评估系统（SITAS）**：面向大学生求职训练、校园招聘模拟和岗位能力评估。核心闭环：

```
简历上传 → 简历解析 → 岗位选择 → 知识库(BM25)检索 → AI 生成问题 → 候选人回答
  → AI 追问与评分 → 生成面试报告 → 保存面试记录
```

技术栈：FastAPI + SQLAlchemy 2.0 + SQLite + Pydantic v2（后端）；Vue3(CDN) + Bootstrap5（前端，无 Node 构建）；DeepSeek API + 本地 BM25 RAG（AI 核心）。

**团队**：成员A DavidChristof（AI核心/RAG，组长）、成员B Aouray（业务后端/数据库）、成员C KazzverF（前端）。

## 4. 技术要点（写文档素材）

1. **RAG**：jieba 分词 + rank-bm25 离线检索，知识库按 `data/knowledge/` 分目录（jobs/questions/companies/standards/samples），`build_index` 幂等（clear+重建）；问题生成与反馈携带检索依据 evidence。
2. **Agent 化面试编排**：`plan_interview` 生成 5 环节问题序列，`generate_followup` 结构化追问，`evaluate_answer` 评分反馈，`generate_report` 生成完整报告；报告含雷达 5 维数据（表达能力/项目实践/专业能力/综合素质/求职动机）。
3. **SQL Agent**：自然语言 → SQLite 查询，白名单校验（仅 SELECT 指定表、拦截注入）。
4. **面试状态机**：pending → running → finished，逐题落库（`interview_answers`），报告缓存于 `report_json`。
5. **前端**：Vue3 CDN 无构建工具，FastAPI 托管静态页；统一 API 封装（`{code,message,data}` + `unwrap`）；canvas 自绘雷达图；Mock 兜底机制。
6. **统一响应**：`{code:0, message:"success", data:{}}`，错误码 1001 参数 / 1002 未找到 / 1003 服务器错误。
