参数
核心目标：面向大学生求职训练、校园招聘模拟和岗位能力评估场景，构建 AI 智能面试官系统。系统需支持简历解析、岗位知识库检索、结构化面试、多轮追问、回答评分、反馈报告、面试记录和后台题库管理，覆盖大模型、RAG、Agent、前端交互和后端管理模块。任务 1：实现简历解析与岗位画像模块，抽取教育经历、项目经历、技能关键词、岗位要求和能力维度。任务 2：建设岗位与面试题知识库，支持岗位说明、企业资料、常见题库、评分标准和优秀回答样例检索。任务 3：实现 AI 面试 Agent，根据岗位、简历和回答内容自动生成问题、追问、评分和改进建议，并调用招聘数据 SQL Agent 与流式语音面试工具。任务 4：实现候选人端，支持简历上传、岗位选择、文字/语音面试、答题记录、评分反馈和报告查看。任务 5：实现 HR/教师后台，支持企业管理、岗位管理、候选人管理、面试官管理、题库管理和面试记录管理。
.设计内容
设计要求
1. 需求分析：明确学生、HR/教师、管理员三类用户的功能边界和操作流程。2. 架构设计：后端提供简历解析、知识库检索、面试编排、评分生成、报告生成和后台管理接口。3. RAG 实现：将岗位 JD、题库、评分规则和企业资料入库，面试问题与反馈需能关联检索依据。4. 大模型实现：设计自我介绍、项目深挖、专业能力、行为面试和反问环节的提示词模板。5. Agent 实现：封装问题生成、追问生成、评分、报告生成、招聘数据 SQL Agent、流式语音面试和面试状态控制工具。6. 前端实现：完成面试大厅、简历上传、面试对话、进度提示、结果报告和历史记录页面。7. 后台实现：完成企业、岗位、候选人、面试官、题库和面试记录等业务对象管理。8. 系统联调：完成从简历上传到面试报告生成的完整闭环。
